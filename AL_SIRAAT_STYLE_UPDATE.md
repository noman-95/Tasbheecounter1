# Quran Learning / Voice Coach Update

This version moves the recitation experience toward the requested Quran-learning reference workflow:

- Word-by-word colored feedback remains persistent per Surah + Ayah.
- Opening an ayah restores its last saved word colors.
- Tapping a word selects it for focused repeat practice.
- First-time offline voice model setup uses a blocking full-screen progress state.
- Arabic matching keeps Quran diacritics in the displayed text and checks returned harakat when the speech engine actually provides them.
- Tajweed learning guidance is shown without claiming that ordinary speech-to-text can fully grade makhraj, ghunnah, madd or qalqalah acoustically.
- Recitation UI is compact and adaptive for mobile heights.
